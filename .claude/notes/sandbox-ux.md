# Sandbox UX round 2 (branch feature/sandbox-ux)

Checklist sb1-sb3.
Amount selection (vacpack and crafter; spawner keeps its slider):
- Shift+scroll on an item sets how many to add; show the amount bottom-right on the icon; tooltip explains how to select several. The amount slider goes away. Multi-select items.
- Vacpack: Shift+scroll on a slot puts items into it; slots are scrollable (scroll changes the amount). Items can be dragged between slots.
- Locked vacpack slots show with a lock icon; hovering turns it into an unlock icon that unlocks the slot (the upgrade).
- Tooltips: item name only, group as a tag next to it.
Tabs: icon-only group tabs next to the search box (no titles):
- Vacpack and spawner: all / plorts / slimes / food / resources, using the game's own icons (drone station target menu in explorer mode has plort, food, crafting-material icons; find a multi-slime one).
- Crafter: all / utilities / warp tech / deco etc. with the blueprint menu's icons.
Crafter:
- Multi-select with a craft button next to the search bar.
- Gadgets without an unlocked blueprint can be crafted straight into the inventory if that works with the game.
- Crafting materials in their own section (horizontal separator). Not-yet-unlocked blueprints at the top.
Right-click menu on items:
- Food: "Give slime" (a slime that has this food as favourite). Slime: "Give food" (its favourite), "Give plort". Design a good UX for favourites (e.g. favourite shown in the tooltip with its icon, related items).
Icons: largos, containers, giant eggs, vine buds have none. Research generating them (e.g. compose two slime icons for largos, render from models).
